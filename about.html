About

ESP32 + DHT22 → Firebase Realtime Database

IOT PROJECT

Environmental monitoring

The ESP32 reads a DHT22 sensor and sends temperature and humidity to Firebase over HTTPS.

🌡️ DHT22

The sensor provides temperature and humidity. In your firmware it is connected to GPIO 4.

📡 ESP32

The firmware connects to Wi-Fi and sends readings every 2 seconds using HTTP PATCH.

🔥 Firebase

The Realtime Database stores the temperature and humidity values at the database root.

💻 Dashboard

This web interface polls Firebase, displays live values, and keeps up to 60 readings locally for charts and history.
